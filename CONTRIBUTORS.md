# Contributing to MineServ

We welcome any and all contributions! Whether you are reporting bugs, fixing issues, suggesting features, or improving documentation, your help is greatly appreciated.

## Contribution Guidelines

1. **Report bugs:** If you encounter any bugs, please open up an issue and let us know the details, error logs, and steps to reproduce.
2. **Contribute code:** If you want to contribute code, please follow our coding standards, test your changes thoroughly against Minecraft 26.3, and submit a pull request.
3. **Suggestions:** If you have awesome ideas for updates or improvements, open up an issue to discuss them with the community.
4. **Documentation:** If you see the need for additional documentation or clarifications, feel free to submit edits!

## AI Assistance Policy

We recognize that AI tools (like code assistants and language models) can be powerful aids during development. However, to maintain code quality, security, and stability across MineServ:

- **AI Usage Limit:** No more than **10%** of any pull request or contribution should be entirely AI-generated boilerplate or untested code.
- **Human Guidance Required:** Every line of code—whether written by a human or assisted by AI—**must** be thoroughly reviewed, verified, and understood by a human contributor. 
- **Responsibility:** The contributor submitting the pull request is fully responsible for the correctness, performance, and security of the code, regardless of whether AI tools were used to help write it.
